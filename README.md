# HVLS 360° — Industry Intelligence

Static editorial website for Big Fan Guys. Designed for GitHub Pages at `https://thefanguys.github.io/HVLS-360/`.

## Deploy
1. Create public repository `TheFanGuys/HVLS-360`.
2. Upload the **contents** of this archive to the repository root.
3. GitHub Settings → Pages → Deploy from a branch → `main` / root.
4. Confirm canonical URLs and configure custom domain only after DNS and hosting are verified.

## Publishing policy
No auto-publishing. All articles must be approved before merging to `main`. Use branch protection requiring a pull request and review; repository owners may need additional protection against bypass.

## SEO
Includes canonical URLs, descriptions, Open Graph, Organization and WebSite JSON-LD, breadcrumb markup, sitemap, robots and RSS. Replace the base URL in the build script and generated files when a custom domain is confirmed. Search Console verification and indexing require a live deployment.

## Research automation
Tuesday and Friday at 08:00 Arizona (America/Phoenix), proposed. Not enabled in this starter: unattended research requires an API/service, credentials, source registry, duplicate checks and an approval-safe draft PR pipeline. Do not place API keys in the public repository.

## Editorial assets
`assets/masthead.png` is a rendered design asset, not a scalable vector logo. Review any trademark/registration marks in the image before commercial use.
