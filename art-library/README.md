# HVLS 360 — Art Department source library

This is the shared source collection for current and future articles. The folder is excluded from GitHub Pages and has no public-site navigation link. This public repository still permits direct GitHub access; it is not private storage.

- `bigfanguys-com/` — website collection by industry, plus brand assets.
- `uploads/` — Chris adds new photographs here using **Add file → Upload files** in GitHub. Subfolders are welcome.
- `catalog.json` — website source URLs, categories and review status. Photographs are web-sized copies with metadata stripped; original URLs remain recorded.
- [Open the Art Desk browser](https://thefanguys.github.io/HVLS-360/office/photo-library.html) — searches this collection and discovers new uploads when opened/refreshed.

## How to add photos

1. Open `art-library/uploads` in GitHub.
2. Choose **Add file → Upload files**, select images and commit.
3. Open or refresh the Art Desk browser. New JPG, PNG, WebP, GIF and AVIF files appear automatically from the repository tree. HEIC/TIFF originals appear as file links until a web copy is prepared.

Helpful names: `warehouse-fan-mount-2026-11.jpg`. An optional text file can record model, photographer, date and intended use. Do not put private customer information in this public repository.

## Art Department work rule

Start every article-image assignment here. Review composition, visible equipment and identifying details before selection. Never infer exact model, measured performance, compliant installation or study participation from a gallery label. Record the chosen image, caption and credit in `editorial/media/article-images.json`; place a selected publication copy in the existing `editorial/media/publisher/` folder. Do not put every source image into a public gallery or keep recycling TAZ imagery for unrelated stories.

New uploads and unreviewed collected images are candidates, not a technical/model clearance. The browser reads GitHub; it does not claim an autonomous image-selection agent is running.
