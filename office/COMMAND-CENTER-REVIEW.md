# Publisher Command Center V1 — Review Instructions

## What is implemented
- Responsive HTML interface at `office/command-center.html`
- Local queue: add, filter, mark approved locally/rejected, remove, export and import JSON
- **New:** Import a `.md` research report generated by the HVLS 360 GitHub research workflow. Parses linked leads into pending research review items, skips duplicate URLs, and labels all leads unverified.
- No external API keys, paid services, or backend.

## How to get a research report
1. GitHub → HVLS-360 → Actions → HVLS 360 Research Desk → select a completed run.
2. Download its `hvls360-research-...` artifact ZIP.
3. Extract the ZIP to get the `YYYY-MM-DD-research.md` file.
4. Open `office/command-center.html` in a browser and choose **Import research report**; select the Markdown file.
5. Review imported leads. This is a **manual import**, not a live connection to GitHub.

## Important limitations
- This HTML page is in a feature branch; it is **not a hosted preview** yet. GitHub's file viewer displays code, not the running app.
- Import does not work directly from the artifact ZIP; extract the Markdown file first.
- Browser storage is device/browser-specific. Export queue backups periodically. Local approval is not publication authorization.
- The research feed currently has unresolved quality issues and may yield zero leads. Empty reports are not silently turned into invented stories.
- No external sharing, advertising spending, outreach, or publishing occurs.
- Browser-level functional testing and iPhone Safari testing remain to be completed.
